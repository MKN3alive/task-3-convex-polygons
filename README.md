# Задание

Реализация класса для работы с выпуклыми многоугольниками на плоскости.

## Операции
- **Пересечение** - нахождение пересечения двух выпуклых многоугольников
- **Проверка на нахождение внутри** - определение принадлежности точки многоугольнику
- **Триангуляция** - разбиение многоугольника на треугольники

## Методы
- **Площадь** - вычисление площади многоугольника
- **Периметр** - вычисление периметра многоугольника

## Проверка
- **Проверка выпуклости** - автоматическая проверка при инициализации из списка вершин

# Virtual environment
